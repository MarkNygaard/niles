# Security Policy

## Reporting a vulnerability

Please email **mnl@dilling.com** with:

- A description of the issue
- Steps to reproduce, if applicable
- The affected component (crate, integration, deployment path)

You can expect an acknowledgement within 7 days. Once a fix is available, disclosure will be coordinated with you.

## Supported versions

Niles is pre-alpha. There are no released versions yet — all security work happens against `main`.
